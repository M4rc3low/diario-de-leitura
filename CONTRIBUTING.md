# Contributing

Thank you for your interest in improving this project.

## Development workflow

1. Create a branch from `main`.
2. Make focused changes.
3. Test the application locally.
4. Open a pull request with a clear description.

## Local checks

Before submitting changes, run:

```bash
npm install
npm start
```

Then open the local application and test the main reading flows.

## Commit style

Prefer conventional-style commits:

```txt
feat: add reading progress filter
fix: correct book cover fallback
docs: improve setup instructions
refactor: organize book search logic
```

## Pull request checklist

- [ ] The application runs locally
- [ ] No API keys or private data were added
- [ ] Documentation was updated when needed
- [ ] Screenshots were added for visual changes when possible
